# 1.8 Snapshots

- [ ] **1.8 Snapshots and restore.** Screenshots: `app-snapshots.png`
      (the window with two snapshots) and `app-snapshot-restore.png` (the
      question before restoring). File → Snapshots…. Open a project with
      a couple of tracks and an effect, type "Lesson 3 end" and press
      Take snapshot. Then change things: move and delete a clip, rename a
      track, add a marker, change the tempo, edit the lesson notes, turn
      a knob on the effect, and write a comment. Press Restore… on the
      snapshot, then Restore. Pass: clips, tracks, markers, tempo, notes
      and the effect's setting are back as they were, the comment you
      wrote is still there, and Edit → Undo puts everything (the knob
      included) back to how it was just before the restore, in one step.
      Save, close and reopen: the snapshot is still listed and still
      restores. Try Rename and Delete… too.
- [ ] **1.8 Snapshots travel with the project.** Export a bundle (or use
      the shared folder) with a snapshot in it and open it on the other
      computer, or as a second copy. Pass: the snapshot is listed there,
      with who took it, and restores there too, audio included, even for
      a clip that had been deleted from the timeline before the bundle
      was made. Someone let in as a commenter sees the list but can't
      take, restore, rename or delete.

## Decisions to accept

- [ ] **What a restore leaves alone.** Built: comments stay as they are
      now (so a deleted comment's words never come back, and newer
      comments aren't lost), and so do each person's practice settings
      (speed, transpose, loop on/off, practice mutes). Everything else
      goes back: tracks, clips, effects and their settings, markers,
      tempo, loop bars, tuning reference and the lesson notes. Say if the
      lesson notes should stay as they are too.
- [ ] **Taking a snapshot isn't an undo step.** Undo is for changes to
      the song; Undo right after Take snapshot undoes your last edit
      instead, and the snapshot stays. Delete… removes it.
- [ ] **Interaction with "real deletion".** A restore reads the project
      from the document's history, so whatever is blanked out of history
      can't come back with it. Comments are already blanked, and aren't
      part of a restore anyway. If lesson notes or takes get the same
      treatment (the open question in `1.8-privacy.md`), a snapshot taken
      before a deletion would restore those parts without the deleted
      words or audio. That seems right for privacy; say if not.

Known limits: a snapshot taken before a project is first saved can't
bring back a take that was later moved into the project folder, once the
project has been closed and reopened (in the same session it can).
Snapshots show who and when, not what changed since (a summary of
changes is roadmap 2.8). Restoring re-loads only the plugins whose
settings differ.
