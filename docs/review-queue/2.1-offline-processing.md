# 2.1 Offline processing

- [ ] **2.1 Normalise, reverse and change gain.** Screenshot:
      `app-clip-processing.png` (a clip's menu with Change gain open).
      Open a project with a guitar clip, trim a little off both ends, and
      right-click the clip. Try Normalise, then Reverse, then Change gain
      → +3 dB, playing after each. Pass: after Normalise the clip's
      loudest moment sits just under full scale (the waveform nearly
      fills the lane); after Reverse it plays backwards, still starting
      and ending where the clip did; +3 dB is clearly louder. The clip's
      name says what was done, such as "guitar (normalised)". Edit → Undo
      three times brings back the original sound, each step in turn, and
      Redo puts them back. Select two clips and Normalise: both change.
- [ ] **2.1 Processed audio is saved with the project.** After processing,
      save, close and reopen the project, and send it as a bundle to the
      other computer. Pass: the processed clips sound the same there, and
      undo there still reaches the original. The original file outside
      the project is unchanged.

## Decisions to accept

- [ ] **Only the part of the file the clip plays is processed.** The new
      file holds just that part, so after processing a clip can't be
      dragged longer than it was. Undo first to lengthen it. Processing
      the whole file instead would keep the extra audio but take longer
      on a short clip cut from a long recording.
- [ ] **Normalise goes to 1 dB below full scale**, leaving a little
      headroom, measured on the loudest sample of either channel.
- [ ] **Change gain offers +6, +3, +1, −1, −3 and −6 dB.** No box to type
      any amount yet. Turning a clip up past full scale is kept (the file
      is 32-bit float) and the app says to turn the track down.
- [ ] **Processed files are 32-bit float WAV**, about twice the size of a
      16-bit recording, so nothing is lost to rounding. They wait with
      the unsaved takes until the project is saved.
