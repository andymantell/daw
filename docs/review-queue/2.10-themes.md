# 2.10 Themes: the foundation

The theme system is in: Valve Glow, Workshop, Vellum and Tidal, each with
a dark and a light set of colours, switched while the app runs. The
mixer window, effect panels and other dense views still need designing
per theme (see research/THEMES.md); this is the base they will use.

Screenshots: `app-theme-<theme>-<dark|light>.png` for all eight, and
`app-theme-window.png` (Settings → Theme).

- [ ] **2.10 Switching.** Settings → Theme. Click each theme, then each of
      As designed, Follow the computer, Dark and Light. Also try Ctrl+K,
      "theme" (Next theme, and Switch light and dark). Pass: the whole
      window changes at once, nothing in the project changes (no unsaved
      mark in the title), and the choice is the same after reopening.
- [ ] **2.10 Readability on your screen.** Use each theme for a few
      minutes with a real song, in daylight and in the evening. Pass:
      text, the playhead, the loop range, meters and waveforms are easy
      to read in all eight. Note any that look muddy (the mock-ups
      flagged this risk for Valve Glow) or too bright.
- [ ] **2.10 Your own theme.** In Settings → Theme, press Copy to edit on
      one theme, change a colour in the file it names, and press Reload.
      Then break a line on purpose (say `style = wobbly`) and Reload.
      Pass: the copy appears as "(yours)", the change shows, and the
      broken file is listed with what is wrong, while the app carries on.
- [ ] **2.10 Speed.** With Vellum (paper grain) and Valve Glow (glow),
      play a long project and scroll and zoom the timeline. Pass: as
      smooth as the other themes.

## Decisions to accept

- [ ] **The light Valve Glow and Workshop, and the dark Vellum and
      Tidal.** The mock-ups only showed one variant of each; I derived
      the others. Look at their screenshots: keep, adjust, or describe
      what you want.
- [ ] **Small changes to the mock-up colours** so every theme passes the
      contrast check: Vellum's and Tidal's dim text is darker, and
      Tidal's teal accent is a little deeper (#1a7a6c instead of
      #1f8a7a), so white text on it reads.
- [ ] **The default.** Built: Valve Glow, "As designed" (dark). Before
      this the app followed the computer's light or dark setting.
- [ ] **Fonts.** Themes set text sizes and whether readouts use
      monospaced figures, but every theme still uses the app's built-in
      typeface. Bundling the faces from the mock-ups (all under the SIL
      Open Font License) is a later step, with their licences shipped
      alongside.
- [ ] **Not yet:** switching by time of day, and the phone remote using
      the theme's track colours.
