# 2.11 Agent interface: AI assistants can drive the app

Settings → **AI assistants…** turns on a server that an AI assistant on
this computer connects to over the Model Context Protocol. It is off
until turned on, listens only on this computer (`127.0.0.1`, port 7346
or the next free one), and needs the token shown in the window. The
first time an assistant calls, the window opens and asks what it may do:
**Look only**, **Edit**, **Edit and export** (also save and write
files), or **Refuse**. **Stop assistants** (Ctrl+Shift+Backspace) turns
the server off and forgets every permission. Screenshot from the cloud
(Linux): `app-ai-assistants.png` in `/mnt/project-files/screenshots/`.

What an assistant can do: list and run any command by its id, read the
project, transport, selection, every track and effect setting with its
range, set any of them by value, seek, select clips, read the meters,
analyse a track, a bus or the mix (maybe without one track) over a time
range (peak, true peak, RMS, crest factor, loudness, loudness range,
stereo correlation, third-octave bands), render a region to a WAV file,
and take a picture of the window or a pane. Each request that changes
the project is one undo step. Commands that open a file chooser are
refused, since they need a person.

All of this was tested in the cloud with a test client speaking the
protocol, not with a real assistant app. The protocol has two eras
(sessions before 2026-07-28, stateless since); the server answers both.

- [ ] **2.11 An assistant connects.** Turn on Settings → AI assistants…,
      open "Settings to paste into an assistant", copy it, and add the
      server to an assistant app on the PC that supports MCP servers
      over HTTP with a header. Ask the assistant what tracks the project
      has. Pass: the AI assistants window asks about the assistant by
      name; after **Look only** the assistant answers with the right
      tracks. If the assistant can't connect, note its name and what it
      says.
- [ ] **2.11 It can change things, and Ctrl+Z takes them back.** Choose
      **Edit** (Forget it first if it was allowed to look only), and ask
      it to turn a track down 6 dB and to turn the loop on. Pass: both
      happen, and Ctrl+Z takes back one request at a time.
- [ ] **2.11 It can hear and see.** Ask it to analyse the bass track over
      the chorus, and to describe the mixer from a picture. Pass: it
      gives levels and a spectrum that make sense, and describes the
      mixer as shown.
- [ ] **2.11 Stop.** Press Ctrl+Shift+Backspace while it is connected.
      Pass: the assistant's next request fails, and the window shows the
      server off.
- [ ] **2.11 Look only means look only.** Allow an assistant to look
      only, and ask it to mute a track. Pass: it says it isn't allowed,
      and nothing changes.
