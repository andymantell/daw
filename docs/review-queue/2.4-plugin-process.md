# 2.4 Plugins in their own process, and presets

Same `daw.exe`. Screenshots from the cloud, with the project's test
plugin: `/mnt/project-files/screenshots/app-plugin-process-choice.png`
(the new column in Settings → Plugins), `app-plugin-crashed.png` (an
effect whose helper crashed, with Restart) and `app-plugin-presets.png`
(the Presets menu).

## On the PC

- [ ] **2.4 A plugin in a helper process.** Settings → Plugins now has a
      column saying where each plugin runs: "In the app", "Shared helper
      process" (the default) or "Its own process". Leave an amp sim on
      the default, add it to a track with your guitar as input, arm and
      monitor. Pass: you hear the guitar through it, the effects window
      shows the delay in samples (the helper adds one audio buffer's
      worth), and Task Manager shows a second `daw.exe`.
- [ ] **2.4 The plugin's own window from a helper.** Click **Edit** on
      that effect. Pass: the plugin's window opens, its knobs change the
      sound at once, closing it and clicking Edit again works, and the
      app's own window stays responsive while it is open. This is the
      part I could not try in the cloud (no Windows there), so say what
      you see if it misbehaves.
- [ ] **2.4 Surviving a crash.** There is no safe way to make a real
      plugin crash on purpose, so this one is only if a plugin ever
      crashes on you: the app should keep playing, the effect should
      show "Stopped: the plugin process crashed", the status line should
      say which plugin, and **Restart** should bring it back with the
      settings from the last save. Every plugin sharing that helper is
      stopped too; those set to "Its own process" are not.
- [ ] **2.4 Latency.** With a backing track and a recorded take, put the
      amp sim on the take's track in the shared helper. Pass: it still
      plays in time with the backing (the extra delay is made up for,
      as a plugin's own delay is).
- [ ] **2.4 "Late" blocks.** Play for a minute with a couple of helper
      plugins. Pass: no "late ×N" tag appears next to them in the
      effects window. If it does, note the audio buffer size you use in
      Settings → Audio device; a bigger buffer gives the helper more
      time, and that is what to try first.
- [ ] **2.4 Running in the app.** Switch a plugin to "In the app",
      remove and re-add it (the choice applies to effects added from
      then on, or when one is restarted). Pass: it works as before 2.4,
      with no extra delay shown.
- [ ] **2.4 Your own presets.** On an effect, open **Presets**, type a
      name under "Save as" and press Save. Change the sound, then pick
      the preset. Pass: the sound comes back. Delete it with ✖. The
      files are `.vstpreset` under `%APPDATA%\DAW\presets`.
- [ ] **2.4 The plugin's own presets.** For a plugin that ships presets
      (most amp sims do), open **Presets**. Pass: its presets are listed
      under "The plugin's presets" or as program lists, and picking one
      changes the sound. The standard folders looked in are `Documents\
      VST3 Presets` and `C:\Users\Public\Documents\VST3 Presets`, each
      laid out `<Vendor>\<Plugin>\`; a plugin may keep its presets in
      its own format somewhere else, in which case only its program
      list (if any) shows. If a plugin's presets you can see in another
      host do not show here, say which plugin.
- [ ] **2.4 A preset from another host.** If you have another host that
      saves `.vstpreset` files, save one there for a plugin you also use
      here, and pick it from "The plugin's presets". Pass: the same
      sound. Our layout follows the published VST 3 preset file format
      from memory of it, so this is the check that it is right.

## Decisions to accept

- [ ] **2.4 Default to the shared helper.** New effects run in a shared
      helper process unless you choose otherwise, trading one buffer of
      delay for crash safety. If the delay bothers you when playing
      live, the default could be "In the app" instead, with the helper
      as an opt-in; say which you prefer.
- [ ] **2.4 Pipes first.** The helper talks over pipes, one block
      behind (decision 0010). If the "late" tag shows up at your buffer
      size, the next step is shared-memory buffers.
