# 2.8 Project templates and snapshot changes

Screenshots: `app-new-from-template.png`, `app-template-band-demo.png`,
`app-save-template-replace.png` and `app-snapshot-changes.png`. (In the
cloud screenshots the arrows and icons show as boxes, as the renderer
there lacks those glyphs; other windows already use the same arrow.)

- [ ] **Start a project from a template.** File → New from template…,
      pick Guitar lesson, Create. Pass: three tracks (Teacher, Student,
      Backing track), sections Warm-up, Song and Try it yourself, 90 BPM,
      the loop on bars 5 to 9, and lesson notes ready to fill in. Edit →
      Undo does nothing (the template is where the project starts), and
      if a project with unsaved work was open, you're asked to save it
      first, as with New project.
- [ ] **Save your own.** Set up a project with a couple of tracks, an
      effect with a knob turned, some markers and notes, and record a
      take. File → Save as template…, call it "Tuesday lesson", Save.
      Then File → New from template…: it is listed under Yours. Create
      it. Pass: the tracks, their volume and pan, the effect with its knob
      where you left it, markers, tempo and notes are all there; the take
      and any comments aren't. Saving again with the same name asks
      before replacing it. Delete… in the list asks, then removes it. The
      file is in `C:\Users\<you>\DAW\Templates`.
- [ ] **What changed since a snapshot.** File → Snapshots…, take one,
      then change things: tempo, rename a track, turn a track down, move
      and add clips, add and move markers, edit the notes and a tab block,
      switch off an effect and turn one of its knobs. Press What changed… on
      the snapshot. Pass: each change is listed in plain words under the
      song, the track, Markers, Lesson notes or Tab, and the list keeps up
      as you edit or undo. Pick another snapshot in "to" to compare two
      snapshots. A commenter can look at changes too.

## Decisions to accept

- [ ] **Which templates come with the app.** Built as placeholders:
      *Empty* (no tracks, 120 BPM, 4/4), *Guitar lesson* (Teacher,
      Student, Backing track; Warm-up, Song, Try it yourself; 90 BPM; notes
      headed "This week" and "To practise") and *Band demo* (Drums, Bass,
      Rhythm guitar, Lead guitar, Vocals; Intro, two verses, three
      choruses, Solo, Outro; 120 BPM). Say which to keep, drop or add,
      and what each should hold. They have no effects yet; now that the
      built-in effects have landed, a template could carry some (say, EQ
      and a little reverb on the guitar tracks).
- [ ] **What a template keeps.** Everything but audio (clips and frozen
      audio) and comments: track names, volume, pan, mute and solo,
      effects with their settings, tempo and time signature (with their
      changes along the song), loop, tuning
      reference, markers, lesson notes and tab blocks. Say if notes or tab
      should be left out, or if a template should keep its audio (say, a
      backing track) too.
- [ ] **"New project" stays empty.** The plain New project still opens an
      empty project in one click; templates are a separate menu item.
      The alternative is for New project to always show the template
      list.
- [ ] **What the change list leaves out.** Comments (a restore leaves
      them alone, so they aren't part of a snapshot), practice settings
      (each person's own), and frozen audio (it follows from clips and
      effects). Changes to a plugin's settings are listed by effect
      ("Changed the settings of Drive"), not knob by knob, as a plugin's
      settings are its own private data. Several clips changed on one
      track read as a count ("3 clips moved or trimmed"); one reads by
      name.

Known limits: a plugin knob turned after the change list was opened
shows once you pick another pair to compare, or press Close and What
changed… again (plugin settings are read on demand, as they are for
saving). Templates aren't
shared with other people; to pass one on, send the file.
