# 3.1 Notes, MIDI keyboards and instrument tracks

Built at risk while the owner was away (plan item A1). The project now
holds notes; instrument tracks play them through a built-in synth, from
a MIDI keyboard or drawn in the note editor; notes can be recorded,
kept after the fact, and taken in and out as standard MIDI files.
Screenshots (drawn by the test harness, whose fonts lack a few icons):
`/mnt/project-files/screenshots/app-note-editor.png`,
`app-instrument-tracks.png` and `app-midi-devices.png`.

Plugin instruments are plan item B2; drum pads, samplers and a synth
of our own are B3. The synth here is a plain one so the whole path can
be heard and tested now.

## On the PC

- [ ] **3.1 MIDI keyboard in.** Plug in a MIDI keyboard (or a
      controller with keys) before or after the app starts. Open
      Settings → Audio device: a MIDI section at the bottom lists the
      inputs and outputs. Pass: the keyboard is listed; unplug and plug
      it again and the list follows within a few seconds, with the
      audio device restarted (a short gap in playback is expected).
- [ ] **3.1 Playing an instrument track live.** Mixer → "+ Add
      instrument track" (or Edit → Add instrument track). It comes with
      the Simple synth and monitoring on (the M button lit). Play the
      keyboard. Pass: you hear the synth with no obvious lag at the
      buffer size you use for recording; velocity changes the loudness
      and brightness; the sustain pedal holds notes; holding more than
      sixteen keys steals the oldest. With no track monitoring or armed,
      the keyboard is silent.
- [ ] **3.1 The instrument window.** Click "Synth" in the track's Input
      column. Pass: wave (saw, square, triangle, sine), attack, decay,
      sustain, release, cutoff and level change the sound as you play;
      the settings survive saving and reopening the project (and show
      in Changes… as instrument changes).
- [ ] **3.1 Recording notes.** Arm the instrument track, press Record
      and Play, play a few bars, stop. Pass: a note clip appears on the
      lane from the first note to the last, named "Take n", with the
      notes where you played them (check against the metronome; the
      recording offset is not applied to notes, as there is no round
      trip through the interface). Play it back: it sounds as played,
      and follows the practice speed and transpose like audio does.
- [ ] **3.1 Overdub or merge.** In the transport bar, "Notes" chooses
      "New clip each pass" or "Merge into the clip there". With a loop
      set and Merge chosen, record a kick on pass one, a snare on pass
      two, hats on pass three. Pass: one clip holds all three; with
      "New clip each pass", each pass makes its own clip on top of the
      last.
- [ ] **3.1 Keep what I played.** With the track monitoring (not armed)
      and Record off, play something good, then press "Keep notes" in
      the transport bar (or Transport → Keep the notes I just played).
      Pass: a clip named "Kept" appears where it was played, holding up
      to the last two minutes of notes; pressing again with nothing new
      does nothing.
- [ ] **3.1 Note clips on the timeline.** Double-click an instrument
      lane's empty space to make a bar-long clip; drag it to move,
      drag its ends to trim (notes stay where they were in time),
      right-click for Mute, Duplicate, Delete and "Edit notes…".
      Pass: all of these work and snap like audio clips; a muted clip
      is silent; notes outside the trimmed clip don't play.
- [ ] **3.1 The note editor.** Double-click a note clip (or View →
      Note editor, E). Screenshot: `app-note-editor.png`. Pass:
      - a click on empty grid draws a note as long as the last one
        drawn, snapped to the grid chosen (bar, beat, 1/8, 1/16, 1/32,
        and the triplets); Alt skips the snap;
      - drag a note to move it in time and pitch; drag its right edge
        to lengthen it; drag in the velocity lane to set velocity (the
        note's shade follows);
      - drag across empty space to select several, Shift-click to add
        one; Delete or Backspace removes them; right-click removes one;
      - the wheel scrolls pitch, Shift + wheel scrolls time, Ctrl +
        wheel zooms time about the pointer;
      - Quantise with Strength 50 % moves notes half way to the grid;
        Swing 33 % at 1/8 gives a shuffle on playback;
      - Transpose ±1 and ±12 move the selected notes (or all);
      - the playhead runs through the editor while playing, and edits
        are heard on the next pass without stopping.
- [ ] **3.1 MIDI out to hardware.** With a hardware synth or a second
      device on a MIDI output, pick it in the instrument window's
      "MIDI output". Pass: the track's notes go to it (set Instrument to
      None to hear only the hardware); stopping sends all notes off so
      nothing hangs.
- [ ] **3.1 MIDI files.** File → Export MIDI file… writes the instrument
      tracks; File → Import MIDI file… (or drop a .mid on the window)
      brings a file in, one instrument track per file track, and sets
      the tempo and time signature if the project was empty. Pass: a
      file exported here opens in another program with the right notes
      and tempo; a file from another program comes in with its notes
      in the right bars.
- [ ] **3.1 Practice features with notes.** Loop a section, slow it to
      50 % and transpose +2. Pass: notes play at half speed and two
      semitones up, in time with any audio tracks.
