# 3.2 CLAP plugins (effects first)

Same `daw.exe`. Plugins in the open CLAP format are now found and used
beside VST 3 ones. Built and tested in the cloud with the project's own
test plugin, which is now also a CLAP effect ("DAW Test Gain (CLAP)",
with a sidechain input, an extra output and a delay that changes). None
of it has been tried with real CLAP plugins or on Windows yet; the
plugin's own window on Windows could only be compiled in the cloud, not
opened. Instruments in this format come later (plan item B2).

## On the PC

- [ ] **3.2 CLAP plugins are found.** Install a CLAP effect or two (free
      ones are easy to find; they go in `C:\Program Files\Common Files\CLAP`)
      and open Settings → Plugins → **Rescan**. Pass: they are listed
      with "Effect · CLAP" beside them, next to your VST 3 plugins. A
      plugin that fails to load is listed with why; send those.
- [ ] **3.2 A CLAP effect on a track.** Add one to a track from the
      effects window, play, and turn its settings in the app. Pass: it
      sounds as it should, the settings move it, and the track stays in
      time with the others (its delay is made up for).
- [ ] **3.2 Its own window.** Press **Edit** on the effect. Pass: the
      plugin's own window opens at the right size for your display's
      scale, turning a knob in it changes the sound and marks the
      project as changed, and closing it and pressing Edit again
      reopens it. Say if the window is tiny, blank, or the wrong size.
- [ ] **3.2 Saved and reopened.** Save with a CLAP effect set up, close,
      and reopen. Pass: the effect is back with its settings. Also
      save one of its settings as a preset of your own (the presets
      row in the effects window), change it, and load the preset back.
- [ ] **3.2 In a helper process.** In Settings → Plugins, set a CLAP
      effect to "Shared helper process" and then "Its own process", and
      re-add it each time. Pass: it plays and its window opens either
      way.
- [ ] **3.2 Check plugins.** Settings → Plugins → **Check plugins** now
      tries CLAP plugins too. Send the report as for 2.4.

## Decisions

- [ ] **Decision 0013** (accepted at risk): CLAP plugins are hosted on
      the plain `clap-sys` bindings, and named in projects by 16 bytes
      made from their text id, so nothing else about projects changed.
      See `docs/decisions/0013-clap-hosting.md`.

## Not done yet

- A CLAP plugin's own preset list (its factory presets). Your own
  presets work.
- Mapping an older version of a CLAP plugin to a newer one: CLAP has no
  standard way for a plugin to say so.
- On macOS and Linux the plugin's window opens as a floating window of
  its own (if it offers one) rather than inside one of ours.
