# 3.2 Plugin instruments

Same `daw.exe`. An instrument track (or one layer of it) can now play a
plugin instrument in either plugin format (VST 3 or CLAP), as well as
the built-in instruments. A plugin with several outputs (a drum plugin
with one per drum, say) can send each output to a bus of its own, as
the drum machine's pads do. Built and tested in the cloud with the
project's own test instruments ("DAW Test Synth" in both formats, each
with an extra "Drums" output). None of it has been tried with real
plugin instruments or on Windows yet.

## On the PC

- [ ] **3.2 A plugin instrument plays.** Add an instrument track, open
      its instrument window, and pick a plugin instrument from the list
      under the built-in ones. Play your MIDI keyboard, then a note
      clip. Pass: it sounds as it should, in time with the other tracks,
      and the pitch wheel, sustain pedal and mod wheel do what they do
      in other hosts. Say which plugins, and what didn't work.
- [ ] **3.2 Its window and settings.** Press **Edit** in the instrument
      window, change a sound, save the project, close and reopen it.
      Pass: the plugin's window opens, and the sound you chose is back
      after reopening. Try a preset of your own from **Presets** too.
- [ ] **3.2 Outputs on buses.** With a plugin that has several outputs
      (most drum plugins do), press **Put each output on a bus** in the
      instrument window, or run Edit → **Put each plugin instrument
      output on a bus**. Pass: a bus named after each output appears
      under the instrument's track; its fader and effects act on that
      drum only, and the rest still play on the instrument's track.
      Set an output back to "Nowhere": it plays through the track again.
- [ ] **3.2 As a layer.** Make the track layered and pick a plugin for a
      layer. Pass: it plays in its key range alongside the other layers.
- [ ] **3.2 In a helper process.** In Settings → Plugins, set the
      instrument to "Shared helper process", then "Its own process",
      and pick it again each time. Pass: it plays either way, in time
      with the other tracks. Live playing from the keyboard is one
      audio block later than in the app's own process: say if you can
      feel it.
- [ ] **3.2 Export with a plugin instrument.** Export the mix and the
      stems. Pass: the instrument is in the mix, lined up with the rest.
- [ ] **3.2 A crash.** If a plugin instrument crashes in a helper, the
      track goes quiet and the instrument window says so with a
      **Restart** button. Pass: Restart brings it back with its
      settings.

## Not done yet

- Plugins aren't told the tempo or where the song is, so arpeggiators
  and tempo-synced effects inside an instrument run at their own
  speed.
- Controllers reach a VST 3 plugin only where it says which parameter
  each one sets, as the format asks; a plugin that maps none ignores
  the mod wheel and the like.
- A note's own tuning and brightness (per-note expression) reach CLAP
  plugins; VST 3 plugins get only its pressure.
- Automation lanes for an instrument plugin's own settings.
- A plugin on a layer plays all its outputs through the layer.
- Audio Units (macOS), as planned for later.

Also fixed on the way: an export with effects running in a helper
process came out one audio block early on those tracks; it now lines up.
