# 3.2 Plugin instruments

Same `daw.exe`. Instrument tracks can now play a plugin instrument in
either plugin format (VST 3 or CLAP) instead of the simple synth, and a
plugin with several outputs (a drum plugin with one per drum, say) can
give each output a track of its own. Built and tested in the cloud with
the project's own test instruments ("DAW Test Synth" in both formats,
each with an extra "Drums" output). None of it has been tried with real
plugin instruments or on Windows yet.

## On the PC

- [ ] **3.2 A plugin instrument plays.** Add an instrument track, open
      its instrument window (the instrument button on the track, or
      View → **Instrument…**), and pick a plugin instrument from the
      list under "Simple synth". Play your MIDI keyboard, then a note
      clip. Pass: it sounds as it should, on time with the other
      tracks, and the pitch wheel, sustain pedal and mod wheel do what
      they do in other hosts. Say which plugins, and what didn't work.
- [ ] **3.2 Its window and settings.** Press **Edit** in the instrument
      window, change a sound, save the project, close and reopen it.
      Pass: the plugin's window opens, and the sound you chose is back
      after reopening. Try a preset of your own from **Presets** too.
- [ ] **3.2 Outputs on their own tracks.** With a plugin that has
      several outputs (most drum plugins do), tick **Own track** beside
      an output in the instrument window, or use Edit → **Give
      instrument outputs their own tracks**. Pass: a track named after
      the output appears under the instrument's track; its fader and
      effects act on that drum only, and the rest still play on the
      instrument's track. Untick it again: the track goes (or, if you
      put something on it, stays without the drum).
- [ ] **3.2 In a helper process.** In Settings → Plugins, set the
      instrument to "Shared helper process", then "Its own process",
      and pick it again each time. Pass: it plays either way, and
      still plays in time with the other tracks (the helper adds one
      audio block of delay, which is made up for by playing the notes
      that much early). Live playing from the keyboard is one block
      later than in the app: say if you can feel it.
- [ ] **3.2 Export with a plugin instrument.** Export the mix and the
      stems. Pass: the instrument is in the mix, and an output on its
      own track has a stem of its own with just that drum.
- [ ] **3.2 A crash.** If a plugin instrument crashes in a helper, the
      track goes quiet and the instrument window says so with a
      **Restart** button. Pass: Restart brings it back with its
      settings.

## Not done yet

- Plugins aren't told the tempo or where the song is, so arpeggiators
  and tempo-synced effects inside an instrument run at their own
  speed.
- Controllers reach a VST 3 plugin only where it says which parameter
  each one sets, as the format asks; a plugin that maps none ignores
  the mod wheel and the like.
- Automation lanes for an instrument plugin's own settings.
- Audio Units (macOS), as planned for later.
- Changing the instrument on a track whose outputs have tracks leaves
  those tracks silent until the new instrument has outputs of the same
  number.

Also fixed on the way: an export with effects running in a helper
process came out one audio block early on those tracks; it now lines up.
