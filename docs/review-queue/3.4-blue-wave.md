# 3.4 Blue Wave (classic synths, S9)

The eight-bit wavetable synth with an analogue filter from the classic
synths plan (`docs/plans/classic-synths.md`), for glassy pads, bells,
digital keys and the 80s sound. Each voice has two oscillators reading
the same table of 64 single-cycle waves; the place in the table (the
**Wave**) is set by hand and swept by its own ADSR envelope, the LFO,
the keyboard and the mod wheel, so the tone moves through the table as
a note plays. Oscillator B sits at its own offset in the table,
transposed and detuned. The oscillators run **Smooth** (band-limited
and interpolated, the sweep continuous) or **Eight-bit** (the waves
rounded to eight bits and read without interpolation, so the top folds
back and a sweep steps from wave to wave), which is the original's own
sound kept as a switch. The two sum into the 24 dB transconductance
cascade low-pass with its own ADSR, key tracking and velocity; the
amplifier has an ADSR; the voices spread across the stereo field. It
is "Blue Wave" in the instrument list, `blue-wave` to assistants,
`add-blue-wave-track` in Ctrl+K.

The ten tables are made in code (`crates/instruments/src/wavetable.rs`),
each a formula over its position, with the last four waves of every
table the plain triangle, pulse, square and saw: Harmonics (a sine
gaining a saw's harmonics one at a time), Resonant (a peak sweeping up
the series), Pulse width, Vowels, Bells, Organ, Glass, Sync, Steps
(staircases) and Folded (a sine into a wavefolder). Nothing is read
from any product.

Every setting is in the shared command table (`instrument.table`,
`instrument.wave`, `instrument.wave_env` and the rest, to
`set_parameter`, `set_parameters` and the automation lanes), the sounds
made in code are listed by `get_instrument` with the settings that make
them, and the end-to-end test `the_blue_wave_is_played_through_the_assistant`
adds the track, reads the table names and characters, voices the glass
pad, plays a chord, and moves the wave by hand from the sine to the saw,
which brightens it.

## Listening

The renders are in the project files under `synths/listening/`
(`cargo run -p daw-instruments --release --example blue_wave_listen -- <dir>`
makes them again). Each is stereo and normalised to the same peak.
They are the ten sounds made in code and three demonstrations.

- [ ] **The tables.** `blue-wave-tables-smooth.wav`: one held chord,
      each table swept by hand from its first wave to its sixtieth over
      two and a half seconds, the filter open, nothing else moving.
      Pass: ten clearly different sweeps, none with a click or a jump
      except where a table is meant to step (Harmonics adds a harmonic
      at a time; Steps changes its stair count). Say which tables are
      keepers and which want redrawing.
- [ ] **Eight-bit.** `blue-wave-tables-eight-bit.wav` is the same
      sweep in the eight-bit character, and
      `blue-wave-up-the-keyboard.wav` plays a saw up the keyboard
      smooth then eight-bit. Pass: the eight-bit version has the grit,
      the stepping between waves, and the folded-back top on the high
      notes that the smooth one lacks, and still sounds like the same
      tables underneath. Say whether eight-bit is too harsh to be the
      sound of the pads, or exactly right.
- [ ] **The pads.** `blue-wave-glass-pad.wav` (Glass table, the wave
      envelope opening the partials over two seconds, B an octave up),
      `blue-wave-resonant-sweep.wav` (Resonant, the envelope sweeping
      the peak up over three seconds and back) and
      `blue-wave-vowel-pad.wav` (Vowels, the LFO moving slowly through
      them). Pass: wide, slow-moving and glassy rather than buzzy; the
      sweeps audible as the tone changing, not as a filter.
- [ ] **Bells and keys.** `blue-wave-wave-bells.wav` (Bells, the wave
      envelope falling from the high partials, B a fifth up) and
      `blue-wave-eighties-keys.wav` (Pulse width, a fast wave envelope,
      velocity to the filter). Pass: bell-like with a clean decay; the
      keys brighter as the velocity rises up the run.
- [ ] **Bass and leads.** `blue-wave-digital-bass.wav` (Harmonics,
      mono, the wave falling from bright to the sine, B an octave
      under), `blue-wave-sync-lead.wav` (Sync, mono with glide, the
      wave envelope as a sync sweep on each note) and
      `blue-wave-folded-lead.wav` (Folded, four voices in unison).
      Pass: the bass clean and round; the sync lead's sweep on each
      note; the folded lead thick without being muddy.
- [ ] **Organ and stab.** `blue-wave-organ.wav` (Organ, gate-like
      envelope, the mod wheel pulls more stops) and
      `blue-wave-eight-bit-stab.wav` (the eight-bit character on the
      Harmonics table, the wave and the filter both falling fast).
      Pass: usable as they are.

## Decisions

- [x] **The filter's input level.** The waves reach the cascade filter
      at 0.3 of full scale, so a clean sine stays clean through the
      filter's soft input stage (its third harmonic 35 dB down). The
      analogue synths here drive it at 0.5 and warm up more. If the
      Blue Wave should warm up like them, the level goes up; the tests
      measure the oscillators and would move with it.
- [x] **Eight-bit as a character switch, not the default.** The plan
      says the aliasing is kept as a switch; the default is Smooth,
      so a new track is clean and Eight-bit is a choice. The original
      only had the eight-bit sound. Keep Smooth as the default, or
      make Eight-bit the default so it sounds like the original from
      the first note?
- [x] **Wave steps in Eight-bit.** In the eight-bit character the
      position rounds to the nearest wave, so a slow sweep steps; in
      Smooth it blends between waves. The original stepped; should
      Smooth step too (with the band-limiting and interpolation kept),
      so only the rounding and the aliasing are the difference?
- [x] **Vintage drift.** The oscillators are digital and hold their
      pitch, so the drift control scatters only the filter cutoff
      (6% an octave) and the envelope speeds (8%) per voice, at 30% by
      default. Keep, or set to 0 so every voice is identical as a
      digital synth's would be?

## Measured

- Sixteen voices with the filter at 2× oversampling: about 16% of one
  core on the cloud box (test limit 25%); the filter is most of it,
  as with the other synths. Eight voices, the default, about 8%.
- A table builds in a few milliseconds in release the first time it is
  used; all ten together hold 5 MB.
- The golden test holds the bells at C4 to 1 dB at five harmonics.
