# 3.4 Drum kit profiles and the learn wizard

Settings → Drum kits… lists the MIDI inputs with the kit profile used
for each, and the profiles on this computer. **Learn a drum kit…** asks
for each pad and zone in turn (kick, snare head, rim and cross-stick,
four toms with rims, hi-hat open, closed and pedal, the pedal's range,
two crashes, ride bow, edge and bell, and a choke), keeps the note each
one sends, and saves the result as a profile file. Pads the kit doesn't
have are skipped. With no profile, inputs use the General MIDI drum map.

Screenshots, from the cloud, in `/mnt/project-files/screenshots/`:
`app-drum-kit-learn.png` (a step, with the warning when two pads send
one note), `app-drum-kit-pedal.png` (the hi-hat pedal's range),
`app-drum-kit-save.png` (naming the kit) and `app-drum-kits.png` (the
profile used for each input). The kit hits were simulated.

Built at risk, before the drum kit instrument: nothing plays drum sounds
from a profile yet. The instrument and the drum staff will read these
profiles.

## On the PC, with the kit

- [ ] **Learn the kit.** Plug in the kit's USB lead, open Settings →
      Drum kits…, and press Learn a drum kit…. Hit each pad as asked;
      press Skip for any the kit doesn't have. For the hi-hat pedal
      steps, hold it down and press Next, then let it up and press Next.
      Pass: each hit moves on by itself, the last three learned are
      shown with their notes, and no "same note as" warning appears
      unless two pads really share a note in the module.
- [ ] **Hi-hat pedal.** Pass: the save step shows a controller number
      with a closed and an open value. If it says nothing about the
      pedal, the kit sends the pedal as notes only: say so, as the
      instrument will need to handle that.
- [ ] **Save and check it sticks.** Name it (the input's name is
      suggested), say whether the notes are the module's own, and press
      Save. Restart the app. Pass: the kit is listed, and the kit's input
      shows it in the list of inputs.
- [ ] **Export it to build in.** Pick it in the list and press Export
      drum kit…. Send the file to be added to `crates/project/kits/` as
      the first built-in profile, so no other computer needs to learn it.
- [ ] **Recognised on another computer.** Once the built-in profile is
      in a release, plug the kit into a computer that has never learned
      it. Pass: a note says the input looks like the kit and its pad map
      is used. Port names differ between systems, so say if it isn't
      recognised and what the input is called there.

## Decisions

- [ ] **General MIDI table.** The default notes follow the General MIDI
      percussion key map as commonly published. The MIDI Association's
      own copy of the specification needs an account to download, so it
      was not checked against: confirm against it, or accept as is.
- [ ] **Recognised kits are used without asking.** When an input's name
      matches a profile, that profile is used and a note says so, rather
      than a question before using it. Accept, or ask each time.
- [ ] **Profiles are per computer.** Learned profiles and the choice per
      input are kept with this computer's settings, not in projects, so a
      project opened elsewhere uses that computer's choice. Accept.
