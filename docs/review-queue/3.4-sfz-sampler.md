# 3.4 Sampler: SFZ libraries, round robins, playing from disk

Same `daw.exe`. Built at risk on 2026-11-01 and not yet played from a
keyboard or heard on the PC. Tests are in `crates/instruments` (the
reader in `sfz.rs`, the library and disk streaming in `library.rs` and
`stream.rs`, the voices in `sfz_player.rs`) and in
`crates/app/src/agent_layers.rs` (an assistant loading a library and
setting its mics). It was tested against Big Rusty Drums v1.100
(Karoryfer, CC0): `git clone https://github.com/sfzinstruments/karoryfer.big-rusty-drums`
gives the same files as the release zip. A two-bar beat an assistant
played on it is in the project files as `sampler/big-rusty-beat.mp3`.

## What was built

- **Load an SFZ sample library…** (the sampler's window, the command
  search, or for assistants `file_command` with `load-sfz`). It plays on
  the sampler track in use, or on a new one named after the file. The
  library stays where it is: it isn't copied into the project, so a
  project that uses one needs the library at the same path on another
  computer. Bundles don't carry it either.
- What it plays: regions and groups, key and velocity ranges,
  controller ranges, round robins (`seq_length`/`seq_position`) and
  random layers (`lorand`/`hirand`), the amplitude envelope (delay,
  attack, hold, decay, sustain, release, and their velocity and
  controller changes), tuning, transposing, pitch bend, level, pan,
  velocity curves, start offsets (and random ones), loops (one shot,
  continuous, sustain), playing backwards, two filters, crossfades by
  key, velocity or controller, choke groups (`group`/`off_by`, fast or
  with the release), polyphony per group and per key, key-switches,
  release triggers with their decay, regions started by a controller,
  `#include`, `#define`, `default_path`, note and octave offsets, and
  controller curves.
- Not played yet, and listed in the window ("Some of its settings
  aren't played yet", with a count of each): EQ bands, envelope shapes,
  controller smoothing, effects in the file, stereo width and position,
  pitch and filter envelopes, LFOs. For Big Rusty that is its *Low cut*
  control (an EQ band, flat by default), the brush stirs' envelope
  shapes, and its limiter.
- **Controls**: every controller the library names becomes a setting,
  shown as a fader (Big Rusty's 83: each drum's close, overhead and
  room mics, pans, tuning, deadening, the hi-hat pedal on controller 4).
  A controller played from a keyboard or pedal moves it too, until the
  fader next moves. The articulation (key-switch) is a setting as well.
- **Normalise** (on by default) gives a quiet library one gain, so its
  loudest sound peaks at −6 dBFS. Velocity layers keep their levels
  relative to each other. It never turns a library down: Big Rusty's
  loudest sound is already near full level, so it plays as recorded.
  (Until 2026-11-01 it turned such libraries down 6 dB, which made Big
  Rusty much quieter than a bass in the second song test.)
- **Key names**: each key the library plays is named from the file's
  `label_keyN`, else its regions' labels, else what their sound files'
  folders share (Big Rusty: "kick 24", "snare 14 center", "hihat 14
  chik"). `get_instrument` lists them for assistants.
- **Playing from disk**: a library over 512 MB of sound keeps the
  first 8192 frames of each sound in memory (more where a region starts
  later) and plays the rest from disk, through a thread that fills a
  ring for each voice. Big Rusty: 4466 sounds, 203 MB in memory. If the
  disk falls behind, the voice waits (silently) rather than skip.
  Exporting and other offline renders wait for the disk instead.
- **The sampler's own zones** get a *Round robin turn* setting (zones
  on the same notes with turns take turns), velocity layers and round
  robins read from file names when adding files (`snare_vl2_rr3.wav` is
  the second layer, third turn), and **Normalise levels**, which gives
  zones on the same note one gain, so their layers keep their spread.

## On the PC

- [ ] Load `Programs/01-full.sfz` from Big Rusty. Pass: it loads in a
      few seconds (a debug build in the cloud took about 7 s), the
      window lists its controls, and nothing is listed as couldn't be
      read.
- [ ] Play the kit from a keyboard or the drum kit. Pass: kick (C2),
      snare (D2) and hats (F#2, G#2, A#2) play; repeated hits sound
      different (round robins); hard hits are louder and brighter than
      soft ones.
- [ ] Hi-hat pedal: move controller 4 (or the *Hi-hat position*
      fader). Pass: the hat opens and closes, and a closed hit cuts an
      open one off.
- [ ] Mics: pull a drum's overhead or room fader down. Pass: that mic
      goes, the close mic stays.
- [ ] Play fast rolls with the library playing from disk, on the PC's
      slowest drive. Pass: no gaps or clicks. If there are, say which
      drive, and the buffer size.
- [ ] Memory: Task Manager with the library loaded. Pass: about
      200 MB more than without it.
- [ ] Export a beat on it. Pass: the export sounds as it played.
