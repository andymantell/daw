# 3.6 Export formats and stems by bus

Screenshot: `/mnt/project-files/screenshots/app-export-formats.png`.
Decision: [0014 export encoders](../decisions/0014-export-encoders.md),
accepted at risk. In the cloud, a FLAC export decoded back exactly the
same samples as the WAV (with a correct checksum), and an independent
decoder read the MP3 and both Opus exports (44.1 and 48 kHz) back at
exactly the mix's length.

- [ ] **Listening, each kind.** With a backing and a guitar take, File →
      Export the whole song once as each file type: WAV, FLAC, MP3 at
      320 kbit/s and Opus at 160 kbit/s. Pass: each opens in Windows'
      own player and in another app (FL Studio or a browser); FLAC sounds
      the same as WAV; MP3 and Opus sound like the mix, with nothing
      missing at the start or the end.
- [ ] **Lined up.** Drop the WAV and the MP3 (or Opus) onto two tracks in
      FL Studio. Pass: they line up, with no gap at the start.
- [ ] **Stems by bus.** In a song with a bus (say, two guitars routed to
      a "Guitars" bus, and a reverb bus that tracks send to), export with
      "Also each bus, as it sounds in the mix" ticked. Pass: one file per
      bus; the Guitars file holds both guitars through the bus's effects
      and fader; the reverb file holds only the reverb; nothing else is
      in either.
- [ ] **Decision 0014.** Accept, or say which encoder to swap.
