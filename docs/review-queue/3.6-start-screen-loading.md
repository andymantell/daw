# 3.6 Start screen and faster loading

Screenshot: `app-start-screen.png` (from the cloud, where arrows and
icons show as boxes because the renderer there lacks those glyphs).

- [ ] **The start screen at launch.** Start the app with nothing to open
      (from the Start menu, not by opening a project file). Pass: the
      Start window shows your recent projects on the left, newest first,
      with when each was last saved, and the templates on the right
      (Empty, Guitar lesson, Band demo, then your own). Clicking a
      project opens it; clicking a template starts a new project from it.
      If the app offers to recover an unsaved project, that comes first
      and the start screen doesn't show.
- [ ] **Recent projects.** Open a project with File → Open project…, then
      save another one with File → Save as…. File → Start screen…. Pass:
      both are at the top of the list, the last one first. A project
      folder that was moved or deleted no longer shows. With fewer than
      eight recent projects, the rest of the list is filled from
      `C:\Users\<you>\DAW\Projects`.
- [ ] **Turning it off.** Untick "Show this when the app starts", close the
      app and start it again. Pass: it opens straight to an empty project.
      File → Start screen… still shows it, and ticking the box turns it
      back on. Escape or Close dismisses it.
- [ ] **Faster opening.** Open a project with many clips (a dozen or more
      audio files, ideally some at another sample rate from the
      interface's, so they need converting). Pass: the status bar says
      "Opening project: 3 of 12 files…" and counts up, and the project
      opens noticeably faster than on a build from before this change
      (up to eight files are now opened at once, instead of one after
      another). Not timed on the PC yet; worth a stopwatch on a big
      project before and after.

## Decisions to accept

- [ ] **Show on every launch.** Built to show whenever the app starts with
      nothing to open, with a box to turn it off. The alternative is to
      open the last project straight away instead.
- [ ] **No separate "Empty project" button.** The Empty template does the
      same thing, so the start screen lists only templates under "Start
      something new". File → New project still starts an empty one in one
      click.
