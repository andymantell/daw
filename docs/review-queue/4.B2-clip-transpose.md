# 4.B2 (first step) Transposing audio clips

Each audio clip has its own transpose, in semitones and cents (up to an
octave either way). It keeps the clip's length and timing, and works on
clips that follow tempo: the stretcher does both at once. The practice
transpose adds on top. By default the clip's formants stay where they
were, so a voice moved into another key still sounds like the same
singer; **Move formants with the pitch** makes it change character too,
like tape played faster or slower.

The clip's name on the timeline shows its transpose ("−6 st", "+2 st
50 ct"). Everything runs through the shared command table:
`transpose-clips` (the Transpose clips window), `transpose-up`,
`transpose-down`, `reset-transpose` and `move-formants`, on the selected
clips and those grouped with them. Assistants use `edit_clip` with
`transpose_semitones` and `move_formants`, and see both in
`get_project`.

How formants are kept: each frame's spectral envelope is taken by
cepstral smoothing, and every frequency is given the envelope where the
resampler will move it, so the harmonics move and the resonances stay.
It is the simple first step of the published method (Röbel & Rodet,
DAFx 2005, use a refined "true envelope"); if it sounds rough on a real
voice, that refinement is the next thing to try.

## On the PC

- [ ] **Into another key.** Import a sung phrase (the a cappella hook
      from song test 2 is a good one). Right-click it → **Transpose…**,
      set −6 semitones, press **Transpose**. Pass: it plays a tritone
      lower, in time, with no clicks or warble at the start, and it still
      sounds like the same singer, not a slowed-down tape. Check it with
      the tuner if you like.
- [ ] **Formants.** Tick **Move formants with the pitch** and transpose
      again. Pass: now it sounds deeper and darker (or chipmunk-like going
      up). Untick it: back to the natural sound. Decide which you want as
      the default for new clips (kept, for now).
- [ ] **Cents.** Set 0 semitones and +30 cents on one of two identical
      clips. Pass: they beat against each other, and the label reads
      "+30 ct".
- [ ] **With follow tempo.** Tick **Follow tempo** on a transposed loop
      and change the song's tempo. Pass: it stretches to the tempo and
      keeps its new pitch.
- [ ] **Practice transpose on top.** With a clip at +2, set the practice
      transpose to +1. Pass: the clip plays 3 semitones up, the others 1.
- [ ] **Export and render.** Export the song, and render the track in
      place. Pass: both have the clip transposed as it plays.
- [ ] **Undo, save, reopen.** Transpose, undo (back to its own pitch in
      one step), redo, save and reopen. Pass: the transpose is kept.
- [ ] **Sound on guitar and drums.** Transpose a guitar part and a drum
      loop with formants kept and moved. Note which sounds better for
      each: keeping formants on a polyphonic part can sound a little
      phasey, as all phase-vocoder shifters do.
