# 4.B2b Pitch editor: snap to the key

A follow-up to pitch editing (4.B2), from song test 3's wish list
(item 24). Plain snapping puts a note on the nearest semitone, so a
note sung about 50 cents off can land on a note outside the song's key.

- **Snap to key** (pitch editor bar, and the command search) moves each
  chosen note, or all of them, to the nearest note of the song's key.
  Between two key notes equally near, it picks the lower. It is greyed
  out until the song has a key.
- **Leave within … ct** (next to it) sets how close a note may already
  be to where it would go and be left alone. It applies to **Snap to
  notes** too. Set it to 30 and one press snaps every note more than
  30 cents off. It is a setting of the pane, not saved with the
  project, and starts at 0.
- Both snaps judge the note as the clip plays it, after the clip's
  transpose: a vocal shifted down 6 semitones snaps to the key it is
  heard in, not the key it was sung in.

Assistants: `edit_pitch_notes` with `snap: "key"` and `min_cents`.

- [ ] **Snap a vocal to the key.** Set the song's key, pick a sung
      phrase with a few notes clearly off, set **Leave within** to 30
      and press **Snap to key**. Pass: the off notes move to notes of
      the key, the notes already in tune are untouched, and nothing
      lands outside the key.
- [ ] **Tell me if the lower note is the wrong choice** for a note
