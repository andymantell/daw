# 4.B3 A practice file per section, and an export queue

Built while you were away (Phase 4 plan item B3, on top of song
sections, A4). Screenshot from the cloud, in
`/mnt/project-files/screenshots/`: `app-export-sections.png` (the
Export window set to a file per section, with one export running and
one waiting).

## On the PC

- [ ] **4.B3 A file per section.** In a song with audio and a few
      sections marked (M), open File → Export…, choose "A practice
      file for each section", untick one section and press Export.
      Screenshot: `app-export-sections.png`. Pass: a new
      `Sections 1` folder appears in the project's Exports folder with a
      file per ticked section, numbered in song order (`01 Verse.wav`,
      `02 Chorus.wav`, …); each starts and ends exactly on its bars, so
      it loops with no gap or click in your usual player. Stems and the
      video copy are greyed out in this mode.
- [ ] **4.B3 To play along with.** Turn on practice mute (🎧) on your
      guitar track, tick "Leave out the tracks muted for practice, to
      play along with" and export again. Pass: the files have the band
      without your guitar. With the box unticked, practice mute is
      ignored, as before.
- [ ] **4.B3 One section from the menu.** Put the playhead in a section
      and run "Export this section as a practice file" from the command
      search (Ctrl+K). File → Export a practice file per section does
      every section. Pass: both use the Export window's file type and
      play-along setting, and open the window to show progress.
- [ ] **4.B3 Export queue.** While an export is running, set the window
      to something else (the whole song as MP3, say) and press Add to
      queue, then once more with another setting. Pass: they are listed
      under "Waiting to export" and run one after another into folders
      of their own; ✕ takes one out and "Clear the queue" (or the
      command "Clear the export queue") takes them all out, leaving the
      one running; every finished file is listed with an Open folder
      button. A queued loop export keeps the loop's bars from when it
      was queued.
- [ ] **4.B3 Try it with your teacher.** Pass: the files are what a
      student wants to practise with. Say if they should also be
      slowed down, repeat a few times, or start with a count-in (see
      below).

## Choices made without you

- Files are cut exactly at the section's bars with no ring-out tail, so
  they loop cleanly; an effect's tail past the end is lost.
- A queued "whole song" or section export uses the song as it is when
  it starts, but a queued loop keeps the loop's bars from when it was
  queued.
- Per-section stems aren't offered: a file per section is the mix only.
- Not built yet, for you to say whether they're wanted: rendering at
  the practice speed, repeating each section several times in its file,
  and a count-in click before it.
