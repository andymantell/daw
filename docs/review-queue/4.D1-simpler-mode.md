# 4.D1 Simpler mode for beginners

Screenshots (from the cloud, where some icons show as boxes):
`app-simple-off.png` and `app-simple-off-edit.png` (the mode off, the
same as before), `app-simple-on.png`, `app-simple-more.png`,
`app-simple-view-menu.png`, `app-simple-search.png` and
`app-simple-key-note.png`.

The mode is off until you turn it on, and with it off nothing in the
app changes.

- [ ] **Turning it on.** View → Simpler mode. Pass: the Notes menu goes,
      the other menus get shorter, and a highlighted "Simpler mode"
      button appears on the menu bar. Clicking that button turns the
      mode off again. Close and reopen the app: it remembers the choice.
- [ ] **More.** With it on, open Edit. Pass: Undo, Split, Delete, the
      markers and copy and paste are there, and the rest is under
      More at the bottom. Choosing Fix timing… from More opens it.
- [ ] **Keys.** With it on, press Ctrl+B. Pass: the content browser does
      not open, and a note at the bottom says it is under More in the
      View menu, or that you can turn the mode off. Everyday keys (Space,
      R, L, K) work as usual.
- [ ] **Command search.** With it on, press Ctrl+K and type "group". Pass:
      no command is listed, with "Show advanced commands too" and how
      many more it found. Ticking it lists them, and they run.
- [ ] **Mixer and timeline.** With it on, pass: the mixer has no Out,
      Sends or Group columns and no bus, folder or control group
      buttons. The timeline has no To clips, Ripple, Volume or Groups
      boxes, and a clip's right-click menu has no Normalise, Reverse or
      Change gain.
- [ ] **With your teacher.** Try a lesson with it on. Note anything they
      missed or didn't need.

## Decisions to accept

- [x] **What counts as everyday.** New, open, save, export and sharing
      bundles; undo, split, delete, markers, copy and paste; zoom, snap,
      the mixer and scrolling with playback; play, record, loop,
      metronome and count-in; tuner, lesson notes, lessons and comments;
      the notation lane, the next notation view and practice-muting a
      part; the audio device and themes; finding a command, checking
      for updates and crash reports. Everything else is advanced. To
      change the list, ask for a command to be marked everyday in
      `crates/app/src/commands.rs`.
- [x] **Advanced keys do nothing.** In the simpler mode an advanced
      command's key shows a note instead of running it, so a stray key
      can't open something unexpected. The alternative is to let every
      key run.
- [x] **Settings stay as they were.** Turning the mode on hides Ripple,
      for example, but leaves it on if it was on. The alternative is to
      turn such settings off when the mode goes on.
- [x] **The agent interface.** It lists every command with whether the
      simpler mode offers it, and still runs any command by id.

## Not built

- The timeline toolbar's own Crossfade and Fades… buttons, the effects
  panels and the note editor still show everything in the simpler
  mode. Say which of those a beginner should not see.
