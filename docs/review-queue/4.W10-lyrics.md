# Wish list 10 (song test 3) Reading the words in a vocal

**Find the words** (Edit menu and command search, `find-lyrics`) reads
the words sung in the selected audio clip, with when each is sung. It
uses a speech model that runs on this computer (decision 0015). The
model isn't in the installer: the first time, a window says what it is
(small, 190 MB, MIT licence, from huggingface.co) and offers to download
it, with base and medium as other choices. The download is checked
before it is used and kept in the app data folder.

The words are drawn along the bottom of each clip cut from that
recording, where each one is sung. Assistants use `find_lyrics` (with
`download_model: true` to fetch the model) and `get_lyrics`, which gives
each word's time from the clip's start, in its file (for `edit_clip
offset_seconds`), in the song, and as a bar.

## On the PC

- [ ] **First use.** Import a sung a cappella (the song 3 vocal is good),
      select it and run **Find the words**. Pass: the Speech model window
      asks first; **Download and find the words** shows progress, and the
      words then appear along the clip's bottom edge, in time with the
      singing.
- [ ] **Speed.** Pass: a minute of vocal takes well under a minute to
      read, and the app stays usable while it does.
- [ ] **Accuracy on your own singing or a lesson recording.** Note any
      words it mishears; if many, try the medium model.
- [ ] **A chop.** Split the clip and check each part shows only its own
      words.
